**Development Approach**

This project was our final year project, developed through close collaboration, using the following tools and practices:

Version Control: GitHub for code management and pull requests

Communication: Discord for real-time discussions, and email for formal updates

Planning: Joint planning sessions for feature design and architecture decisions

**Key Features**

Employee Management: Comprehensive employee profiles and information tracking

Attendance System: Real-time attendance monitoring and reporting

Leave Management: Streamlined leave request and approval workflows

Department Organization: Hierarchical department and team structure

Role-Based Access: Secure access control based on user roles

**Tech Stack**

Frontend: React, HTML, CSS, JavaScript

Backend: JSON-based local storage (LocalDB)

Tools: Git, GitHub, Discord, GitHub Copilot for testing and assistance
